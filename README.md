# 🧩 PuzzleApp  
**A simple and fun puzzle game built with Unity and C#**
![p-10](https://github.com/user-attachments/assets/1ab51e40-6777-4260-a76c-d4178881070f)

## 🎮 Overview  
**PuzzleApp** is a Unity-based puzzle game developed in **C#**, designed to deliver a smooth and engaging gameplay experience with a clean and minimal design.  
It’s an ideal project for developers learning Unity or exploring game logic implementation in C#.

## ✨ Features  
- Fully implemented in **C#** for all game logic and user interactions.  
- Simple and user-friendly **UI**.  
- **2D design**, optimized for multiple screen sizes and devices.  
- Well-structured project with organized folders and scripts.  
- Easily **expandable** to add more levels, challenges, or game modes.  

## 🛠️ Technologies & Structure  
- **Game Engine:** Unity  
- **Programming Language:** C#  

**Main Folders:**  
- `Assets/` → Scripts, sprites, and other game resources  
- `ProjectSettings/` → Unity project settings  
- `Packages/` → Dependencies and package configurations  

**Design Principles:**  
- Object-oriented scripting  
- Clear separation between game logic, UI, and interactions
